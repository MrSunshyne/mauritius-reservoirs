# Mauritius Reservoirs

A GUI to visualize water levels of reservoirs of Mauritius

Built with Vue 3, Vite and Tailwind CSS. Uses [pnpm](https://pnpm.io).

## Project setup

```
pnpm install
```

### Compiles and hot-reloads for development

```
pnpm run serve
```

### Compiles and minifies for production

```
pnpm run build
```

The build is written to `docs/`, which GitHub Pages serves at https://mrsunshyne.github.io/mauritius-reservoirs/.
`pnpm run deploy-gh` builds, commits `docs/` and pushes.
